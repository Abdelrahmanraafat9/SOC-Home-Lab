# Cyber Kill Chain — Practice Scenario

A fictional attack scenario mapped to the 7 stages of the Cyber Kill Chain, for practice.

1. **Reconnaissance:** Attacker researches the target company on LinkedIn and finds employee emails.
2. **Weaponization:** Attacker builds a malicious Word document with a hidden macro.
3. **Delivery:** Document sent via phishing email to an employee.
4. **Exploitation:** Employee opens the file and enables macros, triggering the payload.
5. **Installation:** Malware installs a backdoor on the employee's machine.
6. **Command & Control:** Backdoor connects back to attacker's server for remote control.
7. **Actions on Objectives:** Attacker moves laterally and exfiltrates sensitive data.
