# MITRE ATT&CK Notes

Notes from studying the MITRE ATT&CK Framework as part of my SOC Analyst learning path.

## What is MITRE ATT&CK?
A globally-used knowledge base of adversary tactics and techniques based on real-world observations, used by SOC teams to understand and detect attacker behavior.

## Tactics Explored

### 1. Initial Access (TA0001)
How attackers first get into a network — e.g. phishing, exploiting public-facing applications.

### 2. Execution (TA0002)
How attackers run malicious code on a system — e.g. malicious PowerShell scripts, scheduled tasks.

### 3. Persistence (TA0003)
How attackers maintain access even after a reboot — e.g. registry run keys, new user accounts.

### 4. Discovery (TA007)
The adversary is trying to figure out your environment.

### 5. Defense Impairment (TA0112)
The adversary is trying to break security mechanisms, pipelines, and tooling so defenders can’t see or trust what’s happening.

### 6. Command and Control (TA0011)
The adversary is trying to communicate with compromised systems to control them.
