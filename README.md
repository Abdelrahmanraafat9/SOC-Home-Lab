 # SOC Home Lab A personal home lab built to practice security monitoring, log analysis, and incident response as part of my journey toward becoming a SOC Analyst. ## Goal Build a small-scale SOC environment to train on monitoring, detection, and investigation using real tools and techniques. ## Current Lab Components - Windows 10 (Host machine) — target/SIEM host - Kali Linux (VirtualBox VM) — attacker machine - Isolated network via VirtualBox Host-only Adapter More components (Splunk, Snort, Wireshark captures, investigation reports) will be added as the project progresses
